## Two request shapes, one set of infrastructure

**`/api/assess`** takes one gene. The pipeline is an async generator of stages and the endpoint
serialises them onto an SSE stream held open for the whole run. 2 to 4 seconds.

**`/api/batch`** takes a list. A POST starts a background task on the same container; the task
writes progress and the finished result to DynamoDB, and the client polls for it. 50 genes in
7.5 seconds, 506 genes in 81 seconds.

No new services between the two. Same ALB, same Fargate task, same table.

**ALB and not API Gateway.** The usual argument for API Gateway WebSockets is the 29 second REST
integration timeout. An ALB has no such limit, its idle timeout runs into the thousands of
seconds, and it passes SSE through untouched. One fewer service for a one-person DevOps team.

**Bedrock deployed, direct Anthropic API for local development.** ODDITY runs inside the parent
company's AWS organisation. Bedrock keeps model traffic on a VPC endpoint instead of out through
the NAT, authenticates with IAM instead of a rotated key, and bills where their infrastructure
already bills.

## Where the 81 seconds goes

**Measured:** 506 genes, cold cache, 80.6 seconds wall clock, 482 outbound calls.

| Stage | Elapsed | Calls |
|---|---|---|
| Resolve the condition and the borrow | 0.5s | 1 |
| Resolve 506 symbols to Ensembl ids | 2.1s | 1 |
| Association scores for 474 targets | 2.4s | 1 |
| **Reachability, one call per gene** | **80.5s** | **474** |
| Assess, rank, summarise | 80.6s | 0 |

Three of the four evidence stages are batched and cost about two seconds in total. The fourth is
97% of the run.

**Human Protein Atlas has no batch route.** Every multi-gene syntax returns `[]` with HTTP 200,
which is indistinguishable from not-found, so the client fetches one gene at a time. At 474 calls
against our own 6 requests per second limiter, the token bucket puts a floor at 79 seconds.
Individual responses come back in about half a second, so the constraint is our rate limit and not
their latency.

Three consequences:

1. **Raising the limiter would shorten the run.** HPA publishes no rate limit. 6/s is a number
   chosen to be obviously polite against a public academic API with no stated allowance. An
   undocumented silence is not permission.
2. **A warm cache changes the picture.** Every call is cached on its inputs and keyed to the data
   version, so a re-run of the same list is served from memory. The demo preset is warmed at
   startup.
3. **This is a batch-only cost.** A single-gene assessment makes one reachability call and
   completes in 2 to 4 seconds, which is why single gene keeps its held-open stream.

## Not built: the queue

SQS plus a worker pool plus resumable run state.

The background task already decouples the client from the compute. A queue also decouples the
compute from itself, which is what buys resumability and parallel workers. The trigger is several
full-list runs in flight at once, or runs long enough that losing one to a task restart matters.
Neither is true at three users.

## Cost

One single-gene assessment is one paid model call: about $0.018 on Sonnet 5, $0.004 on Haiku 4.5.
Sonnet's introductory pricing ends 2026-08-31, after which it is about $0.027.

**Batch is not free of model spend.** The outcome axis retrieves, and retrieval can call a
model.

**Below 25 genes batch runs the agent. Above it, the agent is off.** Same gathering, same
arithmetic, same attribution cap, same disagreement rule; trials that publish no readable
comparison come back undetermined rather than read, and the row says so. A 506-gene list with
the agent on would be about $67 at the measured mean, against a $25 daily ceiling, so the gate
is a cost control and not a preference. The rule verdict is the verdict of record
because it is reproducible, and at $0.018 a call a 506-gene list would be $9.11 of adjudication to
work out which few genes are worth spending on. The model read is what you spend on a row once
triage has narrowed the list.

At 1.8 cents a query, per-IP rate limiting at CloudFront matters more than output token caps, and
the pre-computed fallback mode takes a public demo to zero.
